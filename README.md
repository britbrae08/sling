# FaithWords

**Find words. Uncover Scripture.**

FaithWords is a calm, mobile-first Bible-themed word puzzle game presented by **FaithCraft**.

## Current prototype

- Word-connect letter wheel using touch, pen, or mouse
- Crossword-style puzzle board
- 15 Bible-themed starter levels
- No timer; short, low-pressure sessions
- Shuffle and hint controls
- Light-point progression saved locally
- Scripture reward after each completed puzzle
- Level unlocking and replay
- Responsive portrait-first design
- Installable PWA with offline caching
- No framework or build step

## Core loop

> Swipe letters → discover words → fill the board → reveal Scripture → next puzzle

The Bible theme shapes the atmosphere and level rewards without turning the experience into a quiz. The game is designed to feel peaceful, polished, and easy to pick up for a few minutes at a time.

## Public brand

FaithWords is presented by **FaithCraft** and is intended to be played publicly at `faithcraft.agency/faithwords/`.

## Local development

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.
